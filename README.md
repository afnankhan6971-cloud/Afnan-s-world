# Afnan's World

### A Minecraft-Inspired Interactive 3D Developer Portfolio

A personal developer portfolio built around a Minecraft-inspired Overworld environment. It brings together my profile, technical skills, projects, experience, and achievements in an interactive 3D experience.

---

## Overview

**Afnan's World** is a personal portfolio designed to present my development journey through an interactive environment rather than a conventional portfolio layout.

The experience combines a voxel-inspired world with structured portfolio sections, allowing visitors to explore my background, technical interests, projects, and professional journey.

## Features

- **Interactive 3D Overworld** — Minecraft-inspired environment built with Three.js.
- **Hero Section** — Personal introduction and portfolio navigation.
- **About Section** — Profile, education, and background.
- **Skills Inventory** — Technical skills organized into categories, with resume-listed skills distinguished from project experience.
- **Projects Gallery** — Seven project showcases with category filters and individual detail views.
- **Experience Timeline** — Education and professional journey, including my AI internship experience.
- **Achievements Gallery** — Hackathon participation, awards, and other verified activities.
- **Day/Night Environment** — Dynamic day/night visual experience.
- **Ambient Effects** — Fireflies, environmental details, and subtle mouse-based background parallax.
- **Scroll Animations** — Section reveals and interactive card transitions.
- **Responsive Navigation** — Navigation designed for different screen sizes.

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/afnankhan6971-cloud/Afnan-s-world.git
```

Navigate to the project directory:

```bash
cd Afnan-s-world
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

To generate a production build:

```bash
npm run build
```

To run the production build locally for preview:

```bash
npm run preview
```

## Development Notes
